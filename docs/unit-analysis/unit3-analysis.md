# تحليل الوحدة الثالثة: المواطنة والأمان الرقمي

| البند | التفاصيل |
|---|---|
| **عنوان الوحدة** | المواطنة والأمان الرقمي |
| **الصف** | العاشر الأساسي |
| **المحور** | العالم الرقمي، الخصوصية، الإنترنت، التهديدات، المواطن الآمن |
| **الكلمات الرئيسية** | أمن سيبراني، بصمة رقمية، IP، DNS، تصيّد، هندسة اجتماعية، 2FA |
| **الإطار الزمني** | 5 حصص + مشروع ختامي للسلامة الرقمية |

## ملخص الوحدة
تدرّب الوحدة الطالب على فهم العالم الرقمي واستخدامه بوعي: لماذا يكون هدفًا، وكيف تترك بصمة رقمية، وكيف يعمل الإنترنت (IP/DNS/القفل)، وكيف تُميّز التهديدات (برمجيات، تصيّد، هندسة اجتماعية)، وكيف تحمي حساباتك (كلمات مرور قوية، عبارات مرور، مصادقة ثنائية) وتصبح مواطنًا رقميًا مسؤولًا وواعيًا بمستقبل مهني.

## النتائج المرجوة
- يفسّر الأمن السيبراني ومثلث الحماية.
- يميّز البيانات العادية من الحساسة.
- يتحقق من أمان الروابط والمواقع.
- يضع خطة شخصية للأمن الرقمي.

## الأهداف: سوف يفهم الطلبة أن
1. لكل نقرة أثر رقمي.
2. الحذف لا يمحو الأثر دائمًا.
3. كلمة المرور القوية خط دفاع لكنها لا تكفي.
4. الأخلاق والقانون جزء من المواطنة الرقمية.

## المهارات والمعرفة
| المعرفة | المهارات |
|---|---|
| سرية/سلامة/توافر | رسم خريطة رقمية شخصية |
| بصمة نشطة/سلبية، Cookies | بحث عن الأثر الرقمي |
| IP عام/خاص، IPv4/IPv6، DNS | استخدام whatismyip وipconfig |
| تصيّد وهندسة اجتماعية | كشف علامات الخطر |
| Passphrases، 2FA | بناء عبارة مرور وتفعيل 2FA |

## المهمات الأدائية
- جدول مخاطر نشر البيانات.
- خريطة الحسابات المرتبطة بالبريد.
- بطاقة خصوصية (ما/لماذا/من/كم/كيف).
- ثلاث عادات رقمية آمنة.
- مشروع ختامي للسلامة الرقمية.

## أدلة التقييم
أسئلة كل درس + أسئلة الوحدة (8 أسئلة اختيار + مقالي + تحليل مواقف) + اختبارات المنصة + مشروع.

## معايير تقييم
- دقّة التمييز بين الأنواع.
- جودة التوصيات الأمنية العملية.
- الالتزام الأخلاقي (عدم مشاركة كلمات مرور/صور).
- قابلية فهم خطة الحماية المقترحة.

## خطة التعلم
| الحصة | المحور | المخرج |
|---|---|---|
| 1 | عالمي الرقمي | خريطة + مخاطر |
| 2 | الخصوصية والبصمة | بحث عن أثرك + بطاقة خصوصية |
| 3 | كيف يعمل الإنترنت | IP/DNS عملي |
| 4 | التهديدات | تحليل تصيّد وهندسة |
| 5 | المواطن الآمن | عبارة مرور + 2FA + عادات |
