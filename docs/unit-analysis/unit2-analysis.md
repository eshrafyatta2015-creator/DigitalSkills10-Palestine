# تحليل الوحدة الثانية: البرمجة بلغة بايثون

| البند | التفاصيل |
|---|---|
| **عنوان الوحدة** | البرمجة بلغة بايثون |
| **الصف** | العاشر الأساسي |
| **المحور** | الخوارزميات، المتغيرات، صانع القرارات، قوة التكرار |
| **الكلمات الرئيسية** | خوارزمية، مخطط انسيابي، بايثون، متغيرات، معاملات، شرطيات، حلقات، range |
| **الإطار الزمني** | 4 حصص على الأقل + مشروع فكرة تطبيق |

## ملخص الوحدة
تنقل الوحدة الطالب من تفكير المشكلة إلى الخوارزمية والمخطط الانسيابي، ثم إلى لغة بايثون: المتغيرات والثوابت والمعاملات والمنطق، والجمل الشرطية، والحلقات (for/while) والمتداخلة، مع ربط أخلاقي بالخصوصية والتحيّز الخوارزمي وقصص تقنية واقعية (ناسا، Knight Capital، بيتروف، Slammer).

## النتائج المرجوة
- يحلّل مشكلة إلى مدخلات وعمليات ومخرجات.
- يكتب برامجًا بسيطة تستخدم شرطًا وتكرارًا.
- يختبر سلوك البرنامج ويكتشف الأخطاء المنطقية.

## الأهداف: سوف يفهم الطلبة أن
1. التخطيط قبل الكود يقلّل الأخطاء.
2. المتغير صندوق ذاكرة وتسميته مسؤولية.
3. الشروط والحلقات أدوات بناء أي منطق.
4. للبرمجة آثار أخلاقية ومجتمعية.

## المهارات والمعرفة
| المعرفة | المهارات |
|---|---|
| أجزاء البرنامج الثلاثة | كتابة خوارزمية ومخطط انسيابي |
| المعاملات الحسابية والمنطقية | تتبع قيم المتغيرات |
| if/elif/else + Indentation | تصحيح أخطاء شرطية |
| for/while/range + متداخلة | حل مشكلة بتكرار منظم |

## المهمات الأدائية
- حلقة مرحباً لقائمة طلاب مقابل 50 سطرًا.
- برنامج فاتورة كهرباء وBMI.
- قاموس الفصول (if/elif).
- طباعة نسق 1..12345 (حلقات متداخلة).
- مشروع فكرة تطبيق مع مراعاة الخصوصية.

## أدلة التقييم
أسئلة الدرس (تتبّع كود، إكمال، تصحيح أخطاء) + أسئلة الوحدة (MCQ + تتبع أكواد) + اختبارات المنصة.

## معايير تقييم
- صحة التسلسل المنطقي.
- صياغة شروط صحيحة مع نقطتين ومسافات بادئة.
- عدد مرات تنفيذ الحلقة المتداخلة.
- الوعي الأخلاقي في جمع بيانات المستخدم.

## خطة التعلم
| الحصة | المحور | المخرج |
|---|---|---|
| 1 | الخوارزمية والمخطط | خوارزمية + مخطط لرخصة سياقة |
| 2 | المتغيرات والمعاملات والمنطق | تتبع كود + فاتورة |
| 3 | الجمل الشرطية | نظام تقدير + قاموس فصول |
| 4 | الحلقات | for/while + نسق متداخل |
