# تحليل الوحدة الرابعة: الروبوت ونظم التحكم

| البند | التفاصيل |
|---|---|
| **عنوان الوحدة** | الروبوت ونظم التحكم |
| **الصف** | العاشر الأساسي |
| **المحور** | كيف تفكر الأنظمة، الروبوت كنظام، من البيانات إلى القرار، هندسة الأنظمة وتطوير القرار |
| **الكلمات الرئيسية** | نظام، تحكم، تغذية راجعة، مستشعر، وحدة تحكم، مشغل، قرار، جودة، تحيّز، تفكير هندسي |
| **الإطار الزمني** | 4 حصص + مشاريع أردوينو + مشروع إشارة مرور ذكية |

## ملخص الوحدة
تبني الوحدة فهم الطالب للأنظمة المعتمدة على البيانات: من مفهوم النظام ونظم التحكم (مفتوح/مغلق) والتغذية الراجعة، إلى مكوّنات الروبوت (مستشعرات، متحكم، مشغلات، طاقة، هيكل)، ورحلة البيانات إلى القرار، ثم هندسة الأنظمة وتطوير جودة القرار مع التفكير الهندسي والمشاريع العملية (إنارة، متتبّع شمسي، موقف سيارات، إشارة مرور).

## النتائج المرجوة
- يفسّر عمل الأنظمة وتحليل قراراتها.
- يصمم نظامًا عمليًا بالأردوينو وفق خطوات التفكير الهندسي.
- يلتزم باستخدام مسؤول وعادل للتكنولوجيا.

## الأهداف: سوف يفهم الطلبة أن
1. النظام لا يعمل عشوائيًا بل على بيانات ومعالجة وقرار.
2. قد يُنتج النظام قرارًا غير مناسب رغم سلامة المكونات (بيانات/منطق).
3. أكثر من مصدر بيانات يحسّن الجودة (ضوء+حرارة، ضوء+حركة).
4. جودة القرار = دقة وكفاية وارتباط؛ والتحيّز خطر.

## المهارات والمعرفة
| المعرفة | المهارات |
|---|---|
| نظام/تحكم/تغذية راجعة | رسم مخطط نظام ريّ/نقل ماء |
| مكوّنات الروبوت | توصيل دارة LDR + Arduino |
| أنواع أنظمة: تتعلّم/تتوقّع/تتكيّف/متكاملة | مراحل Define→Improve |
| جودة القرار والتحيّز | تحليل قرارات حالة/عامة |

## المهمات الأدائية
- نظام إنارة يعتمد على LDR (أو مع حركة).
- تطوير نظام إنارة الطرق بمرحلة اختبار وتحسين.
- روبوت يتجنب العوائق بثلاث مراحل.
- مشروع: إشارة مرورية ذكية بـ Arduino.
- قضية بحث: Uber 2018 / الأنظمة الذكية 2050.

## أدلة التقييم
أسئلة الدرس (MCQ + مقالي + مقارنة + تصميم) + أسئلة الوحدة + تقييم المشاريع الهندسية + اختبارات المنصة.

## معايير تقييم
- صحة تحديد المدخلات/المعالجة/المخرجات/الراجعة.
- جودة التوصيل والكود وسلامة التشغيل.
- مراعاة الأمان في التصميم.
- عدالة ومناقشة أثر القرار على المجتمع.

## خطة التعلم
| الحصة | المحور | المخرج |
|---|---|---|
| 1 | كيف تفكر الأنظمة | مخطط ريّ + أنواع أنظمة |
| 2 | الروبوت كنظام | دارة إنارة + مكونات |
| 3 | من البيانات إلى القرار | روبوت 3 مراحل |
| 4 | هندسة القرار | موقف سيارات + إشارة مرور |
