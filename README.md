# المهارات الرقمية — الصف العاشر (منصة تفاعلية)

منصة تعليمية عربية (RTL) لمادة **المهارات الرقمية – الصف العاشر الأساسي** وفق الكتاب الفلسطيني، تتضمن:
- 4 وحدات و17 درسًا
- شرحًا مبسّطًا وأهدافًا ومصطلحات
- حلول أسئلة الكتاب مع تمييز مصدر كل حل
- إثراء وتفكيرًا ناقدًا واختبارات قصيرة
- حفظ تقدّم الطالب في المتصفح (LocalStorage)

## الوحدات
1. **علم البيانات** (ص 6–39)
2. **البرمجة بلغة بايثون** (ص 40–81)
3. **المواطنة والأمان الرقمي** (ص 82–116)
4. **الروبوت ونظم التحكم** (ص 117–152)

## التشغيل محليًا
```powershell
cd "DigitalSkills10-Palestine"
npm install
npm run dev
```
ثم افتح الرابط المعروض في المتصفح.

## البناء
```powershell
npm run build
npm run preview
```

## تدقيق المحتوى
```powershell
npm run audit:content
```
يتحقق السكربت من اكتمال حقول كل درس، ومطابقة الأسئلة الصحيحة، وسلامة المعرفات، وخلوّ المحتوى من محارف غير عربية.

## النشر على GitHub Pages
1. أنشئ مستودعًا على GitHub وارفع الملفات.
2. في إعدادات المستودع: **Settings → Pages → Source: GitHub Actions**.
3. سيقوم سكربت `.github/workflows/deploy.yml` بالبناء والنشر تلقائيًا بعد كل push.

> ملاحظة: `vite.config.ts` يستخدم `base: '/DigitalSkills10-Palestine/'` — غيّره إلى `'/اسم-مستودعك/'` إن اختلف اسم المستودع.

## البنية
```
DigitalSkills10-Palestine/
├── src/
│   ├── components/     # الترويسة، الفهرس الجانبي، العودة للأعلى
│   ├── pages/          # الرئيسية، الوحدات، الدرس، البحث، الرحلة
│   ├── data/           # محتوى الدروس (TypeScript)
│   ├── styles/         # CSS (RTL)
│   ├── types/          # الأنواع
│   └── utils/          # حفظ التقدم
├── docs/
│   ├── unit-analysis/  # تحليلات الوحدات التربوية
│   └── content-audit/  # تدقيق مصدر الحلول
├── scripts/            # سكربت تدقيق المحتوى
├── source-materials/   # النصوص المستخرجة من الكتاب (مرجع)
└── .github/workflows/  # النشر التلقائي
```

## تنويه منهجي
- المحتوى مستخلص من الكتاب المدرسي المعتمد.
- الحلول مُعلَّمة بحسب مصدرها (من الكتاب / نموذجية للمعلم / تحتاج مراجعة).
- هذه منصة تعليمية تكميلية غير رسمية.

مادة تعليمية للاستخدام المدرسي في فلسطين.
